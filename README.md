# USB Storage Guard Advanced — مرحلة تأسيس المشروع

**الاسم داخل الواجهة:** USB Storage Guard Advanced  
**الحد المطلوب:** 265,000,000,000 بايت (265 GB عشرياً)  
**المطور:** عمر يحي سيلان

## مهم قبل الاستخدام
هذه الحزمة هي **هيكل مصدر أولي** لسائق KMDF وواجهة إدارة، وليست إصداراً جاهزاً لحظر وحدات USB. ملف السائق الحالي يثبت جهاز تحكم فقط ويعرض واجهة IOCTL تجريبية؛ لا يقوم بعدُ بترشيح USBSTOR ولا يمنع القراءة أو الكتابة. لا تثبّته على جهازك كوسيلة حماية.

تنفيذ الحظر المبكر حسب السعة يحتاج مرشح تخزين حقيقياً واختبارات على أجهزة افتراضية وأقراص مختلفة، ثم توقيع السائق. لا يمكن ضمان منع كل الأجهزة قبل الاختبار.

## محتويات الحزمة
- `Driver/UsbStorageGuard.c` — بداية سائق KMDF تحكمي (Control Device).
- `Driver/UsbStorageGuard.inf` — ملف INF أولي للتعريف.
- `Manager/Program.cs` — واجهة Windows أولية باللغة العربية، مع تعيين كلمة مرور محلية والتحقق منها بواسطة PBKDF2.
- `.github/workflows/build.yml` — بناء أولي على Windows runner يتطلب تثبيت WDK.

## المتطلبات
- Windows 10/11 64-bit.
- Visual Studio 2022 مع Desktop development with C++.
- Windows Driver Kit (WDK) المتوافق مع Windows SDK.
- للاختبار: جهاز افتراضي Snapshot، ويفضل عدم توصيل أقراص مهمة.

## كلمة المرور
الواجهة تحفظ مشتق كلمة المرور (PBKDF2-SHA256 مع salt) بدلاً من النص الأصلي. هذه حماية إعدادات الواجهة فقط في هذه المرحلة؛ لم يتم بعد ربطها بخدمة Windows مميزة وصلاحيات IOCTL للسائق.

## المرحلة التالية
إكمال مرشح التخزين الذي يقرأ سعة الجهاز من طبقة التخزين ويقرر السماح/الرفض، ثم خدمة مميزة تربط الواجهة بالسائق، واختبار سلوك الإزالة والإدراج والقراءة والكتابة. لا تستخدم هذه النسخة لمنع الوصول إلى بيانات حساسة.
